# Contributing

Thanks for helping improve DOMShot.

This repository is for public product information, docs, examples, support, bug reports, and feature requests. The DOMShot application source code is maintained in a private repository.

## Issues

Open an issue for:

- reproducible bugs;
- docs gaps;
- CLI, Node API, or MCP setup problems;
- Chrome extension workflow issues;
- feature requests.

Please use public or sanitized reproduction details. Do not include private URLs, cookies, tokens, API keys, browser profiles, private screenshots, customer data, or authentication state.

## Pull Requests

Pull requests are welcome for small public-docs improvements, example fixes, typo fixes, and support-note clarifications.

This repo does not accept pull requests for proprietary DOMShot application code.

## Security

For security or privacy-sensitive reports, do not open a public issue. Email `me@rubenruiz.dev`.
