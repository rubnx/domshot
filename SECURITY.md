# Security

## Reporting Security Issues

Please do not open public issues for vulnerabilities, exposed secrets, private URLs, private screenshots, or authentication/session problems.

Email `me@rubenruiz.dev` with a concise description and reproduction steps. Include only the minimum information needed to understand the issue.

## Public Issue Safety

When opening public issues:

- Do not paste tokens, cookies, API keys, browser profiles, or auth state.
- Do not attach screenshots from private dashboards or logged-in accounts.
- Replace private URLs and selectors with public examples when possible.
- Use `https://example.com` or another public page for reproduction steps when possible.

## Local Capture Boundary

DOMShot is intended to run capture workflows locally in the browser or local automation environment. Users are responsible for where generated screenshots, reports, browser profiles, and artifacts are stored after capture.
