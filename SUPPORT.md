# Support

Use GitHub issues for public support:

- bugs in the Chrome extension workflow;
- CLI or MCP setup problems;
- docs gaps;
- reproducible capture issues on public pages;
- feature requests.

Please include:

- DOMShot surface: Chrome extension, CLI, Node API, or MCP;
- package version when using `@usedomshot/cli`;
- operating system;
- Node.js version for CLI/API/MCP issues;
- command or config used;
- the public URL and selector or target description, if safe to share;
- expected result and actual result.

Do not include private screenshots, private URLs, cookies, tokens, browser profiles, or customer data in public issues.

For privacy or security concerns, email `me@rubenruiz.dev`.
